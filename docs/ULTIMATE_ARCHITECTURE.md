# Forex Chart Expert Ultimate — Architecture

## Decision stack
1. **Broker truth layer** — MT5 bars + bid/ask are the numerical source of truth; the phone camera never overrides broker prices.
2. **Data quality gate** — history depth, quote sanity, spread, timestamp and stale-data checks.
3. **No-lookahead gate** — only completed candles are eligible for the strategic decision.
4. **Market-regime classifier** — trending / ranging / compression / expansion / balanced.
5. **Multi-timeframe alignment** — primary + two higher timeframes.
6. **Market-structure engine** — pivots, HH/HL, LH/LL, BOS and transition/CHOCH proxies.
7. **Liquidity engine** — prior range sweeps and rejection behavior.
8. **Location engine** — value-low, value-high, mid-range and recent structure zones.
9. **Momentum engine** — RSI, EMA slope, directional strength.
10. **Price-action engine** — engulfing, hammer, shooting-star and abnormal-body detection.
11. **Session/rollover gate** — weekend and rollover protection plus session awareness.
12. **News gate** — configurable high-impact UTC event veto. Unknown news data is treated as unsafe in strict mode.
13. **Risk/reward gate** — structure-based invalidation, dynamic ATR buffer and >=2.2R planned TP2.
14. **Consensus gate** — independent evidence must align; margin and threshold are intentionally strict.
15. **Stability gate** — Android should require repeated consistent decisions before showing an actionable alert.
16. **Audit layer** — every decision should be recorded with features and outcome for future calibration.
17. **Calibration layer (future ML)** — empirical probabilities are learned only from strictly out-of-sample results.

## What 'perfect' means here
No trading system can be made perfect. The engineering objective is to maximize validated expected value and minimize false positives, while being willing to output NO TRADE most of the time.

## ML-ready architecture
A future model can consume the exact feature vector generated by this engine. Recommended models are an ensemble of gradient-boosted trees + calibrated logistic/meta model, with an optional chart-vision model for camera-only verification. Train with rolling walk-forward splits and untouched final test periods.

## Empirical ML layer (added in 8.1)

The deterministic engine now has an optional empirical gate trained on real MT5 history. The training data must come from the same broker/data feed used in live trading. The model is trained chronologically, calibrated on a future validation segment, and evaluated on a never-used test segment. Only a validated artifact is loaded by the bridge.

This is intentionally not "self-learning" on live money. Live observations are logged; model retraining remains an explicit research/deployment step so a noisy market regime cannot silently corrupt the production model.
